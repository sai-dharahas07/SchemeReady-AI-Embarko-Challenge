# 🇮🇳 SchemeReady AI

### Discover Government Schemes. Check Eligibility. Access Benefits.

**SchemeReady AI** is an AI-powered platform designed to help Indian citizens discover government schemes that may be relevant to them. It simplifies scheme discovery through personalized recommendations, eligibility assessment, and AI-powered assistance.

🌐 **Live Demo:** https://schemeready-ai.embarko.app

---

## 📌 About the Project

India has numerous government schemes designed to support citizens in areas such as education, healthcare, agriculture, employment, housing, and financial assistance.

However, finding the right scheme and understanding its eligibility requirements can be challenging.

SchemeReady AI aims to make this process easier by allowing users to provide basic information about themselves and explore government schemes that may match their circumstances.

The goal is to make government scheme information more accessible, understandable, and easier to navigate.

## ✨ Features

- 🔍 **Government Scheme Discovery:** Explore available government schemes.
- 🎯 **Personalized Recommendations:** Discover schemes based on user-provided information.
- 📋 **Eligibility Assessment:** Answer simple questions to understand potential eligibility.
- 🤖 **AI-Powered Assistant:** Get assistance while exploring government schemes.
- 📝 **Action Plan:** Receive useful next steps and guidance.
- 💻 **User-Friendly Interface:** Simple and accessible user experience.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/sai-dharahas07/SchemeReady-AI-Embarko-Challenge
```

### 2. Navigate to the project directory

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

If your project requires API keys or environment variables, configure them in a `.env.local` file using the variables required by the application.

Do not upload secret keys or credentials to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
